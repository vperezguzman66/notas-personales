E-commerce de productos para adulto mayor con movilidad reducida (muletas, vendas, férulas). Repo privado `github.com/vperezguzman66/protadult`. Django 6 + DRF + JWT, dev con SQLite y producción con PostgreSQL. Apps: `users`, `catalog`, `cart`, `orders`, `payments`, `inventory`, `shipments`, `returns`, `admin_panel`. Flujos críticos implementados: checkout → pago (webhook idempotente) → despacho → devolución.
